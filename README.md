# Laboratorio 2 — Decisiones, Ciclos y Métodos en Java

## 📋 Descripción
Ejercicios prácticos sobre estructuras de control:
- Expresiones booleanas y comparaciones
- Decisiones con `if`, `else if` y `else`
- Selección con `switch`
- Ciclos de repetición: `for`, `while` y `do while`
- Declaración y uso de métodos con parámetros y retorno
- Aplicación integradora: Billetera de consola
